            使い方

            はじめに：会員登録とログイン

            1. 「新規登録」でメールアドレスとニックネームを入力し、「仮パスワードを発行」を押します。
            2. 画面に仮パスワードが表示されます（同じものがメールにも届きます）。「このパスワードでログイン」を押すと入力済みのログイン画面に進みます。
            3. 初回ログインでは本パスワードの設定画面が出ます。英字と数字を含む8文字以上で設定してください。
            4. パスワードを忘れたら「パスワード再発行」から。新しい仮パスワードがメールで届き、次のログイン時にもう一度本パスワードを設定します。

            パスワード欄の 👁 を押すと入力内容を確認できます。ログイン状態は次回も保たれます。

            位置情報の利用を聞かれたら「許可」を選んでください。位置情報がないとゲームに参加できません。

            ルームを作る・参加する

            作る人（ホスト）

            1. ロビーで遊びたいモードを選び、制限時間などを決めて「ルームを作成」を押します。
            2. 待機室の右上に出る6文字のコードを押すと、LINE などで仲間に共有できます。
            3. スポットを追加します。名前と半径を入れて「現在地に追加」、または「地図で選ぶ」を押してから地図をタップします。
              • 鬼ごっこ・かくれんぼ：セーフティゾーン（中にいる間は捕まらない場所）
              • 陣取り合戦：奪い合う陣地（1か所以上）
              • すごろく：マス。追加した順に1、2、3…と番号が付きます（2か所以上）
            4. 必要なら参加者ごとに鬼やチームを指定します（「自動」のままでも開始時に割り振られます）。
            5. 全員そろったら「ゲーム開始」。参加者全員の画面が一斉に切り替わります。

            参加する人

            ロビーの「ルームコードで参加」にコードを入れて「参加」。近くで募集中のルームは一覧からも参加できます。開始後のルームには途中参加できません。

            ゲーム画面の見方

            左上
            残り時間、あなたの役割（鬼・逃走者・チーム）、スコア。オレンジの文字は「隠れ時間」や「位置公開」などのお知らせです。
            📡 / 🗺
            地図とレーダーを切り替えます。レーダーは北が上で、中心があなたです。
            ◎
            地図をあなたの現在地に戻します。
            🎙
            AIゲームマスターから、今やるべき指令をもらえます。
            🔊 / 🔇
            実況音声のオン・オフ。
            💬
            実況ログ。赤い数字は未読の件数です。ホストはここからゲームを途中終了できます。
            下のボタン
            「確保する」「チェックイン」「ダイスを振る」など、そのときできる操作が出ます。
            右上の GPS
            位置の精度です。±30m以内なら良好、それより大きいと判定に失敗しやすくなります。

            各モードのルール

            👹 リアル鬼ごっこ

            • 開始直後は「逃げ時間」。その間、鬼は捕まえられません。
            • 鬼は逃走者に捕獲距離（標準15m）まで近づいて「確保する」を押します。
            • 逃走者のレーダーには鬼の方向と距離が出ます。接近アラートの距離に入ると振動と音声で知らせます。
            • セーフティゾーンの中にいる逃走者は捕まりません。
            • 一定間隔で20秒間だけ全員の位置が地図に公開されます。
            • 全員確保で鬼の勝ち。時間切れまで1人でも残れば逃走者の勝ち。「増え鬼」ありだと、捕まった人が鬼になります。

            🫥 リアルかくれんぼ

            • 鬼ごっことほぼ同じですが、鬼のレーダーには「近い・中くらい・遠い」の距離帯しか出ません。光っている輪のあたりに逃走者がいます。
            • 逃走者は隠れ時間のうちに身を隠しましょう。位置公開のタイミングに注意。

            🚩 リアル陣取り合戦

            • 赤と青の2チームに分かれます。
            • 陣地の円の中で「チェックイン」を押すと自分のチームの色になります。相手の陣地も奪えます。
            • 奪われた直後の陣地は、しばらく奪い返せません。
            • 相手チームの位置はレーダーにだけ映ります。
            • 終了時に多くの陣地を持っているチームの勝ち。

            🎲 リアルすごろく

            1. 「ダイスを振る」で目的のマスが決まります（オレンジ色で表示）。
            2. そのマスまで歩き、円の中で「到着をチェックイン」。
            3. AIからミッションが出ます。やり終えたら「ミッション完了」（自己申告）。
            4. 最後のマスに最初に到着した人の勝ち。

            安全に遊ぶために

            • 歩きスマホはしないでください。画面は立ち止まって見ましょう。音声と振動で状況がわかります。
            • 道路への飛び出し、信号無視、私有地や立入禁止の場所への侵入は禁止です。
            • 人の多い場所や駅の構内では走らないでください。
            • スポットは公園や広場など、誰でも入れる安全な場所に置いてください。
            • AIの指令やミッションが危なそうなら、無理に従わず無視してください。

            困ったとき

            位置が取れない
            スマホの設定でブラウザの位置情報を「許可」にしてください。建物の中や高いビルの間では精度が落ちるので、空の開けた場所へ。
            「GPS精度が低すぎます」と出る
            数秒待ってから再度押してください。精度±50m以内でないと確保・チェックインできません。
            音が出ない
            画面を一度タップしてください（iPhoneはタップするまで音が出ません）。マナーモードやメディア音量も確認を。
            画面を閉じたら位置が止まった
            ゲーム中はブラウザを開いたままにしてください。別のアプリに切り替えると位置が送られなくなります。
            途中でページを閉じてしまった
            もう一度開いてログインすれば、参加中のルームに自動で戻ります。
            ホーム画面に置きたい
            iPhoneは共有ボタン →「ホーム画面に追加」、Androidはメニュー →「ホーム画面に追加」。アプリのように起動できます。
